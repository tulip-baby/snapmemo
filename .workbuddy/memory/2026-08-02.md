# 2026-08-02 工作日志

## 瞬时记忆 Web 应用
- 构建了完整的单页面应用 `instant-memory.html`
- 定位：为逻辑思维强但记性差的人提供瞬时记忆辅助
- 纯白极简设计，移动端优先

### 功能模块
1. **首页**：纯白界面 + 居中的语音输入按钮（Web Speech API），语音识别后自动分类添加到对应模块
2. **日程**：今日/本周/本月三视图切换，支持日期+时间录入
3. **SOP**：
   - 日常 SOP：可创建分类（如出门必备、考试必备），每个分类下有可勾选的清单条目
   - 事件 SOP：流程步骤以带编号圆圈 + 向下箭头连接展示，支持多步骤
4. **灵感**：快速记录灵感卡片，显示时间戳
5. **我的**：头像上传、可编辑昵称、数据统计、导入/导出 JSON、清除数据

### 技术实现
- 纯前端 HTML/CSS/JS，零依赖
- 数据持久化到 localStorage
- Web Speech API 语音识别（中文）
- **AI 语义分类引擎**：多维加权评分系统（6个语义维度），替代简单关键词匹配
  - 时间维度（日期/时刻/DDL）→ 日程分
  - 事件维度（会议/出行/约会）→ 日程分
  - 提醒维度（记得/别忘/带上）→ 日常SOP分
  - 流程维度（步骤/先...再.../上线部署）→ 事件SOP分
  - 创意维度（灵感/想法/不如试试）→ 灵感分
  - 结构维度（句子长度/标点/语序）→ 结构性调整
  - 高置信度自动执行+撤回；中低置信度高亮推荐
- **日常SOP 折叠文件夹**：点击展开查看清单，折叠态显示进度（如 2/4）
- **中文日期解析**：增强版，支持"今天/今日/明天/明日/后天/X天后/周X/下周X/X月X号"等日期，以及"早上/下午X点/X点半/晚上X点"等时间（含24小时制转换）
- **手动添加也自动识别**：点击 + 打开添加日程弹窗后，输入标题时自动检测日期时间并实时更新表单字段，下方显示"已自动识别：日期→2026-08-03，时间→15:00"提示
- **日程卡片重排**：标题在左为主体，完成时间以淡紫色圆角标签显示在右侧，不再用录入时间占据最前位置
- **日程三视图重新设计**：日（近7天分组）- 周（近4周分组）- 月（12个月分组），日程按分组标题显示，不再重复出现在多个视图
- **页面切换动画**：cubic-bezier 滑动动画，左滑进入/右滑返回
- **语音降级方案**：手机不支持时自动展开文字输入框 + 6秒超时检测
- **CloudStudio 部署**：已部署到云端，分享链接可访问
- 完整的 CRUD 操作 + 模态弹窗交互

## SnapMemo 账号系统 + 后端服务器 (晚间)

**问题**：换浏览器后 localStorage 数据丢失，用户无法跨浏览器使用

**解决方案**：
- 创建 `server.js` (Express + SQLite + JWT 认证)
- 改造 `instant-memory.html` 前端，添加登录/注册页面作为入口
- 所有数据从 localStorage 迁移到服务器端 SQLite 数据库（`snapmemo.db`）
- 注册后自动创建默认 SOP 数据（出门必备、考试必备、回家必备等）
- 服务端口: 3001，访问地址: http://localhost:3001

**技术栈**: Node.js Express + better-sqlite3 + bcryptjs + jsonwebtoken + cors

**关键改动**:
- 前端：添加登录/注册表单，API_BASE 指向 localhost:3001，token 存 localStorage，401 自动登出
- 后端：RESTful API（/api/register, /api/login, /api/me, /api/data），SQLite 6 张表
- 添加 `app.get('/', ...)` 路由指向 instant-memory.html

**npm install 问题**: better-sqlite3 需原生编译，安装 120 个包约 46s。运行 `node server.js` 启动。
